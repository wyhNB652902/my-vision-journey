# 大二，我决定独自升级

> 没有实验室，没有导师，没有队友。只有一台电脑、一个计划、和 48 周的时间。

---

## 我是谁

智能视觉工程专业，大二上。学校没有 CV 方向的实验室，专业课老师研究方向偏传统图像处理，找不到能带我做项目的导师。身边同学要么在卷绩点，要么在准备考公，没人打竞赛，没人做项目。

**但我想要的不止这些。**

我想做计算机视觉，想打 Kaggle，想复现 ResNet，想在大三前有一份能拿得出手的 GitHub 主页。既然没有现成的环境，那就自己造一个。

---

## 我的计划：Solo 四阶段升级

总周期 **48 周**（2026.09 – 2027.08），从大二上到大二暑假结束。

### 阶段 1 · 地基期（W1–W18，大二上）

- **数学直觉**：3Blue1Brown《线性代数的本质》《微积分的本质》
- **OpenCV 三项目**：文档扫描仪 → 车牌定位 → 手势识别
- **产出**：3 个项目上 GitHub + 3 篇技术博客

### 寒假 · 点火期（W19–W24）

- **PyTorch 入门**：d2l《动手学深度学习》
- **手写 MLP**：纯 NumPy 实现反向传播，MNIST ≥97%
- **产出**：numpy-from-scratch 仓库开张

### 阶段 2 · 核心期（W25–W40，大二下）

- **深度学习**：CS231n + d2l 第 6–10 章
- **复现 ResNet**：从零实现 ResNet-18，CIFAR-10 ≥90%
- **产出**：复现报告博客 + 面试级仓库打磨

### 阶段 3 · 出鞘期（W41–W48，暑假）

- **目标检测**：YOLO 微调 + IoU/mAP 手写
- **Kaggle 实战**：完整打完一场，目标前 10%
- **部署上线**：ONNX + Gradio + Hugging Face Spaces
- **产出**：英文 writeup + 可分享的 demo 链接

## 执行原则

**弹性原则（最重要）：**
> 某周没完成就直接顺延，**不补课、不自责**。实在忙就只做「动手作业」放弃「学习内容」，保住产出线。弃坑的最大原因从来不是慢，是完美主义。

**每周固定节奏：**
- 周一~周五：每天 1.5–2h（60% 学课程 / 40% 写代码）
- 周六：3h 整块项目时间（雷打不动）
- 周日：30min 周报博客 + 下周计划
- 刷题线：Codeforces / LeetCode 每周 ≥3 题
- 留痕线：**一切代码当天 push GitHub，想法当天发博客**
